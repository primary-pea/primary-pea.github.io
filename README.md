# primary-pea.github.io

Team Primary Pea, Women in Data 2026 Datathon ("What's Cooking", Eat track). This repository is the organisation's root site, https://primary-pea.github.io/ : a landing page, the project at a glance, the method, and how to reproduce every number.

- `docs/` is the site; every subfolder with an `index.html` is a page (`/at-a-glance/`, `/method/`, `/reproduce/`).
- `.github/workflows/pages.yml` deploys `docs/` on every push to `main` (Settings → Pages → Source: GitHub Actions).
- Figures in `docs/assets/fig/` are generated by the scaffold (v2.0, data version `afe63e46c26b`); regenerate them there, do not edit them here.
- The deck lives in its own repository (`/ink-and-iron/`), as does the dashboard (`/dashboard/`); do not create folders with those names under `docs/`.

Editing: plain HTML and one stylesheet (`docs/assets/site.css`); no build step. Check a page locally with `python3 -m http.server 8765 --directory docs` and open http://localhost:8765/ .
