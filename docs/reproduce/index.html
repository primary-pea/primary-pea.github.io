Reproduce

Every number, from one command

The whole analysis rebuilds from pinned inputs in about three minutes on a laptop, offline. If your run prints the same data version and the same test count, you have the same panel and the same results as this site.

1 · What you need

  • Git and Python 3.12. The commands below use uv for the environment; plain python3.12 -m venv and pip work too.
  • macOS or Linux (the runner is a bash script). About 1 GB of disk for the environment, three minutes of CPU.
  • No internet after the clone: every input is committed with its provenance. The World Bank and DHS pull scripts are only needed if you want to refresh those inputs.

2 · Get the code

git clone https://github.com/primary-pea/wid-datathon-2026.git
cd wid-datathon-2026

The layout the scaffold expects, relative to the repository root:

sarah/scaffold/          the pipeline: 00_assemble_panel.py … 09_dml_sidebar.py, run_all.sh, tests/, inputs/
sarah/scaffold/inputs/   pinned inputs, each with a *.provenance.json; pull_wb_context.py regenerates the World Bank file
sarah/requirements.txt   the exact package versions
tiana/                   the three WHO GIFNA registry exports and the feature table
subsaharan_data/         the team's World Bank pulls
derived/                 the panel (ssa_panel.csv), its dictionary, readiness table, MANIFEST.json and data_version.txt

3 · Create the environment

cd sarah
uv venv .venv --python 3.12
uv pip install --python .venv/bin/python -r requirements.txt

The pins that matter for the numbers: pandas 3.0.5, numpy 2.5.2, statsmodels 0.15.0, linearmodels 7.0, pyfixest 0.60.0, wildboottest 0.3.2, scikit-learn 1.9.1, scipy 1.18.1. Figures use matplotlib 3.11.1 and plotly 6.3.0 with kaleido 1.1.0; the notebook check uses ipykernel and nbconvert.

7 · Inputs and provenance

Each pinned input in sarah/scaffold/inputs/ sits next to a *.provenance.json with the source URL or API query, the pull or download time, the SHA-256 of the file and the reading rule the assembly applies. The World Bank context file is written by inputs/pull_wb_context.py (indicators SH.MLR.INCD.P3, SP.DYN.TFRT.IN, SP.URB.TOTL.IN.ZS, SL.EMP.TOTL.SP.ZS, SH.DYN.AIDS.ZS, SH.XPD.CHEX.PC.CD, SH.STA.BASS.ZS, SH.STA.ODFC.ZS); constant-dollar income by its own pull; the DHS survey list by an API query recorded in its provenance file; the WHO PCT deworming workbook, the Nunn–Puga ruggedness file and the GFDx legislation years are downloads with their page URL recorded. The registry files in tiana/ are per-country GIFNA exports combined by tiana/combine_gifna_raw.py. The cluster rules that turn registry records into the dose are a 47-line table, inputs/gifna_cluster_rules.csv, and the token map the assembly writes shows which token matched which cluster.

8 · Change something

  • Knobs live in config.py: the lag (LAG = 3), the smallest effect of interest (SESOI_PP_PER_WITHIN_SD = 1.0), the events, the context and team control lists, the event-study window, the bootstrap draws and seed. Change one, re-run, and the report re-tags itself.
  • Paths: SCAFFOLD_REPO_DIR points the assembly at a repository laid out as above; SCAFFOLD_PANEL_DIR at where the panel should live; PY at the interpreter for run_all.sh.
  • Adding a series: drop a country-year file into inputs/ with a provenance file, add one loader call in 00_assemble_panel.py, and the readiness table, manifest and data version pick it up. The tests will refuse a duplicate key or a broken grid.
  • Adding a delivery series is the change we most want someone to make: the ladder row and sub-period control that carry deworming coverage show where a coverage series plugs in.

9 · What the tests check

The grid is complete and keyed once; every input in the manifest exists and hashes to the recorded value; the direct registry features are consistent (a hand recount of one country-year, stock and ever-adopted flags agree, log stocks equal log of stocks); the events table has one row per country; the survey flag is binary and sparse; the headline model reproduces; the bounds, bootstrap and adjusted p-values exist and are sane; the specification curve has the expected size; the event studies ran for both events; the deworming column is present with the expected reading rule.

10 · Limits

The outcome is a modelled series anchored on surveys in 33 of 49 countries; the registry records reporting, not delivery; the within-country design has limited power, which is why the result is a bound; the context ranking is a screening device. None of the code claims causation, and neither should a re-run of it.
